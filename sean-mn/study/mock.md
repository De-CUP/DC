# Mock 이란?

Mock은 테스트에서 실제 의존성을 대체하는 **가짜 객체**다.

실제 DB, 외부 API, 파일 시스템 등을 테스트에서 직접 호출하면 느리고, 불안정하고, 부작용이 생긴다. <br>
Mock은 이걸 가짜 객체로 대채하여 "이 함수가 호출되었을 때 이 값을 돌려줘." 라고 미리 정의한다.

## 용어 구분

| 용어 | 설명 |
|------|------|
| **Stub** | 미리 정해진 값을 반환하기만 함 |
| **Mock** | 호출 여부, 횟수, 인자까지 검증 가능 |
| **Fake** | 실제 동작하는 경량 구현체 (인메모리 DB 등) |
| **Spy** | 실제 객체를 감싸서 호출 정보를 기록 |
